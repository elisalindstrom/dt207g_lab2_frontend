Om webbplatsen

Syftet med webbplatsen är att hämta och visa arbetserfarenheter från ett REST API. Genom formulär går det att lägga till nya arbetserfarenheter och fylla på CV:et på startsidan. Hämtad data sorteras efter startdatumet för anställningen så att de senaste jobben visas först. Det går även att ta bort arbetserfarenheter från API:et, CV:et uppdateras baserat på aktuell data. PostgreSQL används som databas och både backend och frontend är publicerade via Render.

Det har varit kul att få lära sig mer om hur webbtjänster faktiskt fungerar rent praktiskt. Jag tycker att jag fått ökad förståelse för hur själva hämtningen av data från ett API faktiskt går till då jag tidigare endast sett själva frontend-delen.
